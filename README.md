# ⚡ Advanced Time-Series Forecasting

### Household Energy Consumption Prediction Using Machine Learning & Deep Learning

This project develops and compares machine learning and deep learning models to forecast household electricity consumption using historical time-series data.

## 📌 Project Overview

The project uses the UCI Individual Household Electric Power Consumption dataset to identify energy usage patterns and predict future electricity demand.

**Key features:**

* Data cleaning, missing-value handling, and hourly resampling.
* Exploratory data analysis and time-based feature engineering.
* Lag features, rolling statistics, and cyclical encoding.
* Chronological train-test splitting.
* Model evaluation using MAE, RMSE, and R².

## 🤖 Models Implemented

* Linear Regression
* Random Forest
* Gradient Boosting
* Long Short-Term Memory (LSTM)

## 🛠️ Tech Stack

Python · Pandas · NumPy · Scikit-learn · TensorFlow/Keras · Matplotlib · Seaborn

## 🚀 Getting Started

1. Clone this repository.
2. Install the required Python libraries.
3. Download the [UCI Household Power Consumption Dataset](https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption).
4. Place `household_power_consumption.txt` in the project directory.
5. Open and run the Jupyter Notebook.

## 📊 Results

The project compares forecasting models using MAE, RMSE, and R², with visualizations of actual versus predicted electricity consumption.

## 🎯 Objective

Explore how machine learning and deep learning can support accurate energy-demand forecasting and smarter energy management.
